# Prime Shot - Marketing Website

This is the marketing website for Prime Shot, an AI photo generation app that creates professional headshots and dating profile photos.

## Features

- **Modern Design**: Clean, responsive design built with HTML, CSS, and JavaScript
- **Privacy Focused**: Comprehensive privacy policy addressing face data collection and usage
- **App Store Compliant**: Addresses all App Store review requirements including face data handling
- **Support Section**: Complete FAQ and contact information

## App Store Review Requirements Addressed

### Guideline 1.5 - Safety (Support URL)
- ✅ Functional support page at `/support.html`
- ✅ Contact information and in-app support details
- ✅ FAQ section addressing common user questions

### Guideline 2.1 - Information Needed (Face Data)
- ✅ Complete explanation of face data collection in privacy policy
- ✅ Detailed description of face data usage and processing
- ✅ Clear information about third-party sharing and storage
- ✅ Retention policy and user control options
- ✅ Specific privacy policy sections identified

## Deployment

This website is designed to be deployed on GitHub Pages:

1. Push this repository to GitHub
2. Enable GitHub Pages in repository settings
3. Set source to `/docs` folder
4. Website will be available at `https://username.github.io/repository-name`

## Customization

To customize for your app:

1. Replace placeholder images in `/assets/images/`
2. Update contact email addresses in support and privacy pages
3. Modify app store links in the download section
4. Adjust color scheme in `style.css` if needed

## Face Data Compliance

The privacy policy specifically addresses Apple's face data requirements:

- What face data is collected
- How it's used for AI photo generation
- Third-party sharing policies
- Data retention and deletion options
- User rights and controls

This ensures compliance with App Store Guidelines section 2.1 regarding face data handling.
